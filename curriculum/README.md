# Mees curriculum workspace

This folder separates real learning-route design from synthetic engine test data.

## Status model
- draft_for_validation: proposed structure, not yet a curriculum claim.
- validated: reviewed against authoritative Dutch primary mathematics sources and internal didactic criteria.
- production: validated goals with reviewed question families and representations.

## Current rule
Files in test-data remain engine fixtures. They must not silently become the production curriculum.

## Validation gate
Before a group route becomes production:
1. verify scope and terminology against authoritative Dutch curriculum/reference material;
2. check prerequisite relationships;
3. define success evidence per goal;
4. create at least two question families where appropriate;
5. define representation changes that add pedagogical value;
6. review language for the age band;
7. test the route in the session engine and Focus Mode UX.

The child UI must not expose internal mastery labels or curriculum IDs.
